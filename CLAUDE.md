# GP26_Labs

Lab code and lab manuals for GPU Programming (GP26, in English). Each `Lab_N/` holds the CUDA sources and `manual.md`; `make` builds the manuals into `pdf/`, `make publish` copies them into the Moodle content tree.

## Commits and versions
- English, [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/): `type(scope): subject`.
- Version tags follow [SemVer 2.0.0](https://semver.org/).
