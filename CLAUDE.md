# GP26_Labs

Public student repo for GPU Programming (GP26). It is generated: each `Lab_N/` holds the starter code and `manual.pdf` of one lab.

Do not edit here. The sources (manuals, starter code, solutions) are in the private repo `GP26_Labs_src`; `make publish` there copies the files into this checkout, and they are committed here afterwards.

Commits: English, Conventional Commits 1.0.0.
